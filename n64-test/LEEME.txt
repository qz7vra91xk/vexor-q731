PMOS · Nintendo 64 · CONTROLES MÓVILES v3

INSTALACIÓN
1. Conserva copia de los archivos actuales de n64-test en GitHub.
2. Sustituye SOLO index.html, app.js y style.css dentro de n64-test/.
3. NO reemplaces n64-games.json (se adjunta idéntico únicamente para consulta).
4. Confirma GitHub Pages. Prueba en pestaña privada de Brave/Chrome para evitar la caché.

CAMBIOS
- Corregidos valores reales de control N64 según el código de EmulatorJS: A=0, B=1, L=10, R=11, Z=12; analógico 16-19 y C 20-23.
- Un solo joystick visible en vertical. La cruceta secundaria se muestra en horizontal.
- Botones más compactos, borde táctil y separación, sin Fast/Slow que estorbaban.
- Se conserva el selector de núcleo, la ubicación Cloudflare y el mismo gameID para guardar/cargar estados.
- No se ha modificado la resolución interna del juego, ya que depende del motor.

PRUEBA EN SAMSUNG
1. Con el mismo NFC, inicia el juego y gíralo a horizontal.
2. Prueba B, A, palanca, Z, L, R y cuatro C.
3. Prueba cargar una partida ya guardada.
4. Si alguna tecla no funciona, repórtala: no cambies gameID.
5. Si falla el renderizado, restaura los 3 archivos anteriores.

AVISO: CSS y sintaxis comprobados; no ha sido probado con el emulador completo en un Samsung físico.
